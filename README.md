# Tally-PlugIn-OCR-Automation-
*OCR-to-Tally Invoice Automation Automates manual bill entry for medical distributors.Uses Python and Gemini 2.5 Vision API to extract line items and tax data from unstructured invoices into an editable review UI,pushing verified entries to Tally via API in one click and auto-creating missing inventory items.Early inbound interest after live demos.
