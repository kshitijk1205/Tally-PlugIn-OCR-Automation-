## OCR-to-Tally Invoice Automation

**Problem:** Medical distribution businesses employ dedicated 
staff solely for manual bill/invoice data entry into Tally.

**What I built:** End-to-end pipeline — unstructured invoice 
goes in, Gemini Vision API extracts structured line items and 
tax data, editable review screen appears, single click pushes 
verified entry directly into Tally. Auto-creates new inventory 
items if they don't exist in the ledger.

**Outcome:** Demoed to business owner and industry professionals. 
Early inbound interest ahead of planned commercial release.

**Tech:** Python · Gemini 2.5 Vision API · Tally API
